# BookMyGrounds - User Guide

## 🎯 Getting Started

### For Players (Book Grounds)

1. **Register**
   - Click "Login" in the navbar
   - Expand "Create new account"
   - Select **"Player"** option
   - Fill in your details
   - Click "Register as Player"

2. **Login**
   - Enter your email and password
   - Click "🔐 Login"
   - You'll see: ⚽ YourName (Player) in navbar

3. **Browse Grounds**
   - Go to "Discover" tab
   - Use search and filters
   - Click on any ground to see details
   - View all images in the gallery

4. **Book a Ground**
   - Select a ground
   - Choose a date
   - Pick an available time slot
   - Fill in booking details
   - Submit booking

5. **Manage Bookings**
   - Go to "Customer" tab
   - View all your bookings
   - See booking status
   - Make payments
   - Cancel if needed

6. **Add Favorites**
   - Click "🤍 Save Favorite" on any ground
   - Access favorites in "Customer" tab
   - Quick access to your preferred grounds

---

### For Ground Owners (Manage Grounds)

1. **Register**
   - Click "Login" in the navbar
   - Expand "Create new account"
   - Select **"Ground Owner"** option
   - Fill in your details
   - Click "Register as Ground Owner"

2. **Login**
   - Enter your email and password
   - Click "🔐 Login"
   - You'll see: 🏟️ YourName (Owner) in navbar

3. **Add Your Ground**
   - Go to "Admin" tab
   - Click "New Ground" button
   - Fill in ground details:
     - Name, description
     - Ground type (Cricket, Football, etc.)
     - Surface type
     - Address and location
   - **Use the map** to set exact location:
     - Search for your address
     - Or click "📍 Current" for GPS
     - Or click on the map
   - Select amenities (Parking, Washrooms, etc.)
   - Click "Create Ground"

4. **Upload Images**
   - After creating ground, scroll down
   - Click "Choose Files" under "Upload Images"
   - Select up to 5 images
   - First image becomes the featured image
   - Click "Upload"

5. **Set Pricing**
   - Select your ground
   - Scroll to "Pricing Plans" section
   - Enter duration (hours)
   - Set weekday price
   - Optional: Set weekend price
   - Click "Add Pricing"

6. **Generate Time Slots**
   - Select your ground
   - Choose a date
   - Click "Generate Hourly Slots"
   - Slots created based on opening/closing hours
   - Repeat for each day you want to open

7. **Manage Bookings**
   - View all bookings in "Admin Bookings" panel
   - Click on a booking to see details
   - Actions available:
     - **Confirm**: Accept the booking
     - **Complete**: Mark as finished
     - **Cancel**: Reject or cancel

8. **Update Ground Info**
   - Select your ground
   - Edit any field
   - Click "Update Ground"

9. **Manage Images**
   - View all uploaded images
   - Delete unwanted images
   - Primary image shown with "Featured" badge

## 🔧 Troubleshooting

### Can't see Admin tab?
- Make sure you registered as "Ground Owner"
- Check your role in Account tab
- Contact support if needed

### Images not uploading?
- Maximum 5 images allowed
- Save the ground first
- Check file size (max 10MB per image)
- Supported formats: JPG, PNG, WebP

### Slots not showing?
- Generate slots for the specific date
- Check opening/closing hours are set
- Refresh the ground data

### Booking failed?
- Check if slot is still available
- Verify all required fields
- Ensure you're logged in
- Check payment method

### Map not loading?
- Check internet connection
- Allow location access for GPS
- Try searching for address instead
